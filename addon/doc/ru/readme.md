## Зачем терпеть шумные веб-страницы?

Современные сайты переполнены повторами, рекламными метками, уведомлениями о куки, счетчиками комментариев, боковыми панелями и автоматически созданным мусором, который программы чтения с экрана вынуждены зачитывать снова и снова.

**Invisible** возвращает контроль вам.

Решайте сами, какие слова, фразы или шаблоны NVDA должна полностью пропускать — или тихо заменять на что-то более короткое, чистое или просто на тишину.

<br><br>

Это не просто фильтрация. Это **персональная аудио-курация** для интернета.

## Мощно, но при этом изящно просто

*   Полное скрытие текста — NVDA ведет себя так, будто его никогда не существовало
*   Замена раздражающих меток короткими заглушками («Реклама · Спонсорский контент» → «пропуск»)
*   Применение правил к одной странице, всему домену или сложным шаблонам URL (regex)
*   Полная поддержка регулярных выражений для хирургической точности
*   Мгновенный эффект — перезагрузка страницы не требуется
*   Контекстно-зависимый интерфейс: двойное нажатие открывает «Добавить сайт» с уже заполненным текущим URL
*   Поддержка правой кнопки мыши + клавиши Delete для быстрого управления
*   Портативные .json файлы для каждого сайта — легко бэкапить или делиться

## Начните менее чем за 30 секунд

1.  Перейдите на любую страницу, где NVDA читает что-то, что вы хотите заглушить или изменить.

2.  Нажмите **NVDA + Shift + W**<br><br>
    → Одиночное нажатие → открывает основное окно управления<br>
    → Двойное нажатие (быстро) → открывает диалог «Добавить новый сайт» с уже заполненным текущим URL

3.  В диалоге **Добавить сайт**:<br><br>
    • Оставьте или отредактируйте отображаемое имя<br>
    • Выберите область действия:<br>
    &nbsp;&nbsp;– Только одна страница<br>
    &nbsp;&nbsp;– Весь веб-сайт (домен)<br>
    &nbsp;&nbsp;– Регулярное выражение (расширенное сопоставление URL)<br><br>
    Нажмите **Сохранить**

4.  Теперь вы находитесь в менеджере правил сайта:<br><br>
    • Введите шаблон, который хотите скрыть<br>
    • Введите текст замены — или оставьте пустым для полной тишины<br>
    • Отметьте «Использовать как регулярное выражение», если нужно<br>
    • Нажмите **Добавить** (или **Обновить** при редактировании)<br><br>
    Изменения применяются мгновенно — возвращайтесь к просмотру и слушайте.

<br>

Вы можете вернуться в любое время, нажав **NVDA + Shift + W** (одиночное нажатие), чтобы отредактировать, добавить новые правила, удалить записи или переключиться между сайтами.

## Реальные примеры, экономящие время каждый день

| Шаблон (Target) | Замена | Regex? | Что вы услышите вместо этого |
| :--- | :--- | :--- | :--- |
| Реклама | (пусто) | Нет | — полностью пропущено — |
| Спонсорский контент | пропуск | Нет | «пропуск» |
| · [0-9,]+ комментари.* | (пусто) | Да | — без счетчиков комментариев — |
| Срочные новости: | Новости: | Нет | Короче и чище |
| ^Уведомление о куки.*принять | (пусто) | Да | Текст баннера заглушен |

## Советы для продвинутых пользователей

*   Правой кнопкой мыши по любому сайту или записи → контекстное меню «Изменить / Удалить»
*   Нажмите клавишу **Delete** на выбранном элементе для мгновенного удаления
*   Используется сопоставление «сначала самое длинное» → это помогает избежать проблем с частями слов
*   Импорт правил из другого .json файла напрямую в любой сайт
*   Режим Regex поддерживает группы замены — очень мощно для динамического контента
