## Зачем мириться с шумными веб-страницами?

Современные сайты полны повторений, спонсорских меток, уведомлений о cookie, счётчиков комментариев, боковых панелей и автоматически генерируемого мусора, который экранные читалки вынуждены озвучивать — снова и снова.

**Invisible** возвращает вам контроль.

Решайте точно, какие слова, фразы или шаблоны NVDA должен полностью пропускать — или тихо заменять чем-то более коротким, чистым или полностью молчаливым.

Это не просто фильтрация. Это **личная аудиокурация** для веба.

## Мощный, но элегантно простой

- Полностью скрывать текст — NVDA ведёт себя так, будто его никогда не было
- Заменять раздражающие метки короткими плейсхолдерами («Sponsored · Advertisement» → «skip»)
- Применять правила к одной странице, целому домену или сложным шаблонам URL (regex)
- Полная поддержка регулярных выражений для хирургической точности
- Мгновенный эффект — без перезагрузки страницы
- Контекстно-зависимый интерфейс: двойное нажатие открывает «Добавить сайт» с уже заполненным текущим URL
- Поддержка правой кнопки мыши + клавиши Delete для быстрого управления
- Портативные файлы .json для каждого сайта — легко сохранять или делиться

## Начните менее чем за 30 секунд

1. Перейдите на любую страницу, где NVDA читает что-то, что вы хотите заглушить или изменить.

2. Нажмите **NVDA + Shift + W**  
   - Одиночное нажатие → открывает главное окно управления  
   - Двойное нажатие (быстро) → открывает диалог «Добавить новый сайт» с уже вставленным текущим URL

3. В диалоге **Добавить сайт**:  
   - Оставьте или измените отображаемое имя  
   - Выберите область действия:  
     - Только текущая страница  
     - Весь сайт (домен)  
     - Регулярное выражение (расширенное сопоставление URL)  
   - Нажмите **Сохранить**

4. Теперь вы в менеджере правил сайта:  
   - Введите шаблон, который хотите затронуть  
   - Введите текст замены — или оставьте пустым для полной тишины  
   - Поставьте галочку «Использовать как регулярное выражение», если нужно  
   - Нажмите **Добавить** (или **Обновить** при редактировании)  
   Изменения применяются мгновенно — возвращайтесь к просмотру и слушайте.

Вы можете вернуться в любое время с **NVDA+Shift+W** (одиночное нажатие) для редактирования, добавления правил, удаления записей или переключения между сайтами.

## Реальные примеры, которые экономят время каждый день

| Целевой шаблон              | Замена        | Regex? | Что вы услышите вместо         |
|-----------------------------|---------------|--------|--------------------------------|
| Advertisement               | (пусто)       | Нет    | — полностью пропущено —        |
| Sponsored                   | skip          | Нет    | «skip»                         |
| · [0-9,]+ comments?         | (пусто)       | Да     | — без счётчиков комментариев — |
| Breaking News:              | News:         | Нет    | Короче и чище                  |
| ^Cookie notice.*accept      | (пусто)       | Да     | Текст баннера заглушен         |

## Профессиональные советы для продвинутых пользователей

- Правая кнопка мыши на сайте или записи → контекстное меню Редактировать / Удалить
- Нажмите клавишу **Delete** на выбранном элементе для мгновенного удаления
- Используйте буквальное совпадение самой длинной строки первым → избегает проблем с частичными словами
- Импортируйте правила из другого файла .json прямо в любой сайт
- Режим regex поддерживает группы замены — очень мощный инструмент для динамического контента
