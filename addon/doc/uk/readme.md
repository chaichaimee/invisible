## Навіщо терпіти шумні веб-сторінки?

Сучасні веб-сайти переповнені повторами, рекламними мітками, повідомленнями про куки, лічильниками коментарів, бічними панелями та автоматично згенерованим сміттям, яке програми читання з екрана змушені зачитувати знову і знову.

**Invisible** повертає контроль вам.

Вирішуйте самі, які саме слова, фрази чи шаблони NVDA має повністю пропускати — або тихо замінювати на щось коротше, чистіше або просто на тишу.

<br><br>

Це не просто фільтрація. Це **персональна аудіо-курація** для інтернету.

## Потужно, але водночас елегантно просто

*   Повне приховування тексту — NVDA поводиться так, ніби його ніколи не існувало
*   Заміна дратівливих міток короткими заглушками («Реклама · Спонсорський контент» → «пропуск»)
*   Застосування правил до однієї сторінки, всього домену або складних шаблонів URL (regex)
*   Повна підтримка регулярних виразів для хірургічної точності
*   Миттєвий ефект — перезавантаження сторінки не потрібне
*   Контекстно-залежний інтерфейс: подвійне натискання відкриває «Додати сайт» із уже заповненим поточним URL
*   Підтримка правої кнопки миші + клавіші Delete для швидкого керування
*   Портативні .json файли для кожного сайту — легко створювати резервні копії або ділитися

## Почніть менш ніж за 30 секунд

1.  Перейдіть на будь-яку сторінку, де NVDA читає щось, що ви хочете заглушити або змінити.

2.  Натисніть **NVDA + Shift + W**<br><br>
    → Одне натискання → відкриває основне вікно керування<br>
    → Подвійне натискання (швидко) → відкриває діалог «Додати новий сайт» із уже заповненим поточним URL

3.  У діалозі **Додати сайт**:<br><br>
    • Залиште або відредагуйте назву для відображення<br>
    • Виберіть область дії:<br>
    &nbsp;&nbsp;– Тільки одна сторінка<br>
    &nbsp;&nbsp;– Весь веб-сайт (домен)<br>
    &nbsp;&nbsp;– Регулярний вираз (розширене зіставлення URL)<br><br>
    Натисніть **Зберегти**

4.  Тепер ви перебуваєте в менеджері правил сайту:<br><br>
    • Введіть шаблон, який хочете приховати<br>
    • Введіть текст заміни — або залиште порожнім для повної тиші<br>
    • Позначте «Використовувати як регулярний вираз», якщо потрібно<br>
    • Натисніть **Додати** (або **Оновити** при редагуванні)<br><br>
    Зміни застосовуються миттєво — повертайтеся до перегляду та слухайте.

<br>

Ви можете повернутися в будь-який час, натиснувши **NVDA + Shift + W** (одне натискання), щоб відредагувати, додати більше правил, видалити записи або перемикатися між сайтами.

## Реальні приклади, що економлять час щодня

| Шаблон (Target) | Заміна | Regex? | Що ви почуєте натомість |
| :--- | :--- | :--- | :--- |
| Реклама | (порожньо) | Ні | — повністю пропущено — |
| Спонсорський контент | пропуск | Ні | «пропуск» |
| · [0-9,]+ коментарі.* | (порожньо) | Так | — без лічильників коментарів — |
| Термінові новини: | Новини: | Ні | Коротше та чистіше |
| ^Повідомлення про куки.*прийняти | (порожньо) | Так | Текст банера заглушено |

## Поради для досвідчених користувачів

*   Правою кнопкою миші по будь-якому сайту чи запису → контекстне меню «Редагувати / Видалити»
*   Натисніть клавішу **Delete** на вибраному елементі для миттєвого видалення
*   Використовується зіставлення «спочатку найдовше» → це допомагає уникнути проблем із частинами слів
*   Імпорт правил з іншого .json файлу безпосередньо в будь-який сайт
*   Режим Regex підтримує групи заміни — дуже потужно для динамічного контенту
